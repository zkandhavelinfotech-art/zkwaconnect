🚀 Phased Delivery Strategy
Agile Milestone Progression

Rather than attempting an unstable monolithic build, the WhatsApp Business API Onboarding & Management module is partitioned into five distinct, self-contained, enterprise-tested releases:

MILESTONE 1
Meta Integration Foundation
Facebook Login for Business, Embedded Signup v4, App OAuth & Config.
MILESTONE 2
Automated WABA Creation
Portfolio & WABA selection, Phone OTP, WABA ID & Phone ID persistence.
MILESTONE 3
Client Portal WhatsApp Settings
Live number display, quality rating, health monitor, account disconnect safety.
MILESTONE 4
Onboarding Automation Engine
14-status tracking, automatic retry engine, webhook listeners & audit logs.
MILESTONE 5
Manual Setup & Admin Console
Super Admin SaaS owner onboarding on behalf of tenants, support tickets, Twilio tier.
1 Release 1 — Meta Integration Foundation
Foundation Layer

Establishes the platform-level developer infrastructure, secure secrets management, Facebook Login for Business SDK launcher, Embedded Signup v4 configuration, and backend token exchange service.

Core Deliverables

  • ✓
    Meta Developer App Configuration: Configure Business App ID, App Secret, Config ID, and Graph API v25.0 endpoints.
  • ✓
    Embedded Signup v4 Client SDK: Load Facebook JS SDK with version: 'v25.0' and Tech Provider OAuth handler.
  • ✓
    Backend Token Exchange API: Secure server-side exchange of Meta OAuth code for system user access token.
  • ✓
    Scopes Verification: Validate whatsapp_business_management, whatsapp_business_messaging permissions.

API Endpoints & Test Criteria

POST /api/whatsapp/onboarding/initiate
GET /api/whatsapp/onboarding/config
POST /api/whatsapp/onboarding/exchange-token
Verification Criteria
  • Embedded Signup modal opens without popup blockers or origin errors.
  • Authorization code successfully exchanged without exposing secret to client.
  • Tokens encrypted and stored in backend secrets table.
2 Release 2 — Automated WABA Creation & Phone Verification
Core Automation

Guides customer through Business Portfolio selection, WABA creation/connection, WhatsApp profile configuration, phone number OTP verification, and 2-step registration on the Meta Cloud API.

Core Deliverables

  • ✓
    Business Portfolio Selection: Support selecting existing portfolio or creating new verified portfolio in modal.
  • ✓
    WABA Setup: Account creation with business name, category, website, and timezone attributes.
  • ✓
    Phone Number OTP: Real-time SMS and Voice OTP verification directly inside Embedded Signup flow.
  • ✓
    Identifier Retrieval: Automatic retrieval of WABA ID and Phone Number ID (retaining both independently).
  • ✓
    Phone Registration API: Execute POST /{phone_number_id}/register to set 6-digit PIN and activate line.

API Endpoints & Test Criteria

POST /api/whatsapp/onboarding/callback
POST /api/whatsapp/accounts/connect
POST /api/whatsapp/accounts/{id}/register
Verification Criteria
  • Both WABA ID and Phone Number ID persisted in database.
  • Phone number transitions from PENDING to CONNECTED on Meta network.
  • Test WhatsApp message sent and received successfully via Cloud API.
3 Release 3 — Client Portal WhatsApp Settings & Management Hub
Client Experience

Transforms the settings page into an enterprise WhatsApp Management Hub displaying the verified live number, connection health diagnostics, quality ratings, messaging tier, and safe account management.

Core Deliverables

  • ✓
    Hero Connection Overview: Prominent display of connected WhatsApp number (e.g. +91 98765 43210) and status badge.
  • ✓
    Asset Details Card: WABA ID, Phone Number ID, Portfolio ID, Business Name, Country, Timezone, and Quality Rating.
  • ✓
    Tri-Partite Health Monitor: Visual health indicators for API Connection (Active), Webhook (Active), and Phone Registration (Complete).
  • ✓
    Live Status Sync & Disconnect Safety: 1-click "Refresh Status" and protected "Disconnect WABA" dialog with confirmation modal.

API Endpoints & Test Criteria

GET /api/whatsapp/accounts
GET /api/whatsapp/accounts/{id}/status
POST /api/whatsapp/accounts/{id}/disconnect
Verification Criteria
  • Connected number immediately visible upon returning from Meta signup.
  • Quality rating and messaging limit accurately synced with Meta Graph API.
  • Zero token or sensitive credential exposure in client DOM or JSON payload.
4 Release 4 — Onboarding Automation Engine & Webhooks
✅ 100% Code Complete & Deployed (Commit 4bfb745)

Implements the 14-state lifecycle tracking engine, automatic failure detection, exponential retry logic, sanitized customer error translation, and real-time webhook listeners.

Core Deliverables

  • ✓
    14-State Lifecycle Engine: Deterministic transitions from NOT_STARTED through CONNECTED or ACTION_REQUIRED.
  • ✓
    Automated Retry Mechanisms: 1-click retries for token exchanges, phone registrations, and webhook subscriptions.
  • ✓
    Error Sanitizer: Converts cryptic Meta error codes (e.g. (#133010) Phone already registered) into clear customer action steps.
  • ✓
    Real-Time Webhooks Listener: Subscribed to messages, message_template_status_update, and account_update.
  • ✓
    Immutable Audit Logs: Timestamped records in WhatsAppOnboardingLogs with sanitized vs raw error duality.

API Endpoints & Test Criteria

POST /api/whatsapp/accounts/{id}/retry
POST /api/whatsapp/webhooks/meta
GET /api/whatsapp/onboarding/logs
Verification Criteria
  • Simulated Meta timeout gracefully transitions to ACTION_REQUIRED with retry.
  • Raw Meta codes hidden from customers but visible in internal audit log.
  • Webhook payload signature verified using X-Hub-Signature-256.
5 Release 5 — Manual Setup, Super Admin Console & Pricing Add-ons
Enterprise Operations

Delivers the Super Admin delegated onboarding console (allowing SaaS product owner to setup and onboard tenants on behalf of clients), manual assistance workflows, audit log viewer, and optional Twilio add-on pricing tier.

Core Deliverables

  • ✓
    Super Admin Delegated Console: SaaS product owner can view all tenant onboarding sessions and configure WABA assets on customer's behalf.
  • ✓
    Manual Setup Support Tickets: When MANUAL_REVIEW triggers, ticket auto-created with customer details & error snapshot.
  • ✓
    Permission & Asset Validation Hub: Admin can verify Meta Business Manager partner shares without bypassing OAuth security.
  • ✓
    Marketing & Pricing Plans: Updated public marketing page showcasing Free Starter, Growth Business, Enterprise Pro, and Twilio Global Add-on.
  • ✓
    Twilio ISV Add-on Architecture: Optional gateway tier for international SMS fallback, voice OTP, and global cross-border routing.

API Endpoints & Test Criteria

GET /api/admin/onboarding/sessions
POST /api/admin/onboarding/manual-setup
GET /api/admin/meta-setup
Verification Criteria
  • Super admin can inspect failed tenant onboarding sessions and diagnose Meta error.
  • Admin cannot bypass OAuth without verified partner asset delegation.
  • Public marketing and pricing tables accurately display the 4 tiers including Twilio.
