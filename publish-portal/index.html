2. Server Deployment Targets

Deploying on GoDaddy / cPanel Hosting

You can deploy ZKWAConnect on GoDaddy using cPanel's Node.js App Selector and MySQL Database.

  1. Create MySQL Database in cPanel: Name it zkwaconnect_db, create a database user, and assign ALL PRIVILEGES.
  2. Import Schema: Open phpMyAdmin, select your database, and import prisma/schema-mysql.sql.
  3. Extract Deployment ZIP: Extract the downloaded ZKWAConnect-v6.0.0-DEPLOY-LIVE.zip into your application directory.
  4. Configure Subdomains in cPanel:
    • zkwaconnect.in → Document Root: public_html
    • app.zkwaconnect.in → Document Root: public_html/app
    • api.zkwaconnect.in → Document Root: public_html/api
  5. Setup Node.js App in cPanel: Select Node.js version 20+, App Root: /home/user/zkwaconnect, Application Startup File: server.js.

Deploying on Ubuntu / VPS with NGINX & PM2

Run all 3 applications simultaneously using PM2 process manager and NGINX domain routing.

# 1. Extract ZIP or Clone repository
git clone https://github.com/zkandhavelinfotech-art/zkwaconnect.git
cd zkwaconnect && git checkout v6.0

# 2. Configure MySQL Database in .env
DATABASE_URL="mysql://zkwaconnect:YourStrongPassword@localhost:3306/zkwaconnect"

# 3. Import MySQL Schema
mysql -u zkwaconnect -p zkwaconnect < prisma/schema-mysql.sql

# 4. Install & Build
npm install
npm run db:switch mysql
npm run build

# 5. Start with PM2
pm2 start ecosystem.config.js --env production
pm2 save && pm2 startup
